**S5 rclone GUI in the awake strip.** Browse configured remotes, pick source files/folders and destination (main or public), show progress and errors. Main and public permissions stay independent: never expose private files through a public remote. Reuse the storage/ledger model; no duplicate file manager; freeing disk is a transparent workflow, not an upsell.

**S6 Arq extras.** Add a monthly restore drill to `backup-status`. Never call the backups reliable before a representative restore passes.

**G6 Rooms: the main-gallery social container.** Intent: a trusted-circle space that can replace messaging. A Room is a shared folder; every upload is a post and its own conversation; the media is a canvas people build on (vlog, pitch, tune, poem, sketch, recipe, practice take, long-distance life update). Talk can be about the media or about life; replies return to the upload; history stays until removed. Audience: cross-border and long-distance families and friends, people merging two places, and everyday users who'd rather talk in photo galleries without iCloud quota worry. Exclusive and tunable: only people the owner trusts can advise. Build from small primitives, no feature sprawl:
1. **Room** = folder + members (role, perms, expiry) + per-media overrides. Invite = per-person private link to one folder; revocable; no account needed.
2. **Post** = upload + thread. Consecutive comments unlimited (owner too), likes, owner moderation.
3. **Annotation** = comment with an anchor {time | image region | text range | page/margin} and an optional JSON payload. `audio.preset` = {high, mid, low, key, room, rate}: a viewer taps "play with my settings" and the player applies it non-destructively (G8 uses the same parameters).
