## Planned `[ ]`

### P1 · Dual-mode squeeze
- Native forwards every squeeze phase: began, changed, ended, cancelled, with `hoverPose.location`.
- Released before $T_{hold} = 250\ \text{ms}$ → today's palette toggle (unchanged).
- Held $\ge 250\ \text{ms}$ → radial menu opens at the hover point.
- Release over an item → pick it; release in the deadzone → close, no pick.
- Respect the system squeeze setting: `UIPencilInteraction.preferredSqueezeAction`
  (iOS 17.5, checked in SDK 27.2). If it is "ignore", do nothing.
- Guarded by BUG-01.

### P2 · Radial menu
- Deadzone radius 28 pt (no item picked inside it).
- Inner ring, ink tools, radius 68 pt.
- Outer ring, `::` macros, radius 112 pt. Empty until `::` macros exist (not in repo today).
- Hit-test: item = f(angle, distance from centre); pure function, unit-tested.
- **Every item is also in a visible menu** (the palette); the squeeze only makes it faster.
- **Reduce Motion:** the menu appears and closes without motion.

### P3 · Pencil haptic on snap
- Use `UICanvasFeedbackGenerator.pathCompleted(at:)` for `shapeSnap`.
  Checked: present in `iPhoneOS27.2.sdk` `UICanvasFeedbackGenerator.h`, iOS 17.5+.
- Fallback when unavailable: today's `UIImpactFeedbackGenerator(style: .medium)`.
- Snap timing stays 500 ms; P1's 250 ms is a different gesture.

### P4 · Barrel-roll chisel nib (backlog)
- Nib angle: $\theta_{nib} = \rho + \alpha + \theta_{offset}$
  - $\rho$ = roll (`UITouch.rollAngle`, iOS 17.5, checked in SDK)
  - $\alpha$ = azimuth; $\theta_{offset}$ = nib's set angle.
- Width: $W = f \cdot \sqrt{(W_{max}\cos(\phi-\theta_{nib}))^2 + (W_{min}\sin(\phi-\theta_{nib}))^2}$
  - $\phi$ = stroke direction; $f$ = pressure factor.
  - Convention: $\phi = \theta_{nib}$ → $W = f \cdot W_{max}$.
- Assumption: adding roll and azimuth is exact only for an upright pencil.
- Roll reaches the web view only through a native bridge
  (web pointer events lack roll — from memory, verify).
