## One home and embodiments (spec law, PLAN-1118 §11b)
- **Home (one source):** the woven page is drawn by the editor, `editor/src/` (JS), the one renderer every host loads.
  Hosts: `mobile/HostApp/iOS/Draftpad.swift` (iPhone, iPad) and `strip/editorhost.swift` (Mac). Swift is glue: it opens the document, plays the media, supplies the clock.
- **Embodiments:** iPhone `[ ]` · iPad `[ ]` (same view, wider column) · Mac `[ ]` (its Home panel, later; strip broadcast is FEAT-28) · web `n/a` (the web already has the Draftpad PWA; `editorpwa`).
- **Second copy to delete when built:** the Swift `TranscriptView` (`shared/ShowsKit/Sources/ShowsKit/Views/Transcript.swift:222`) stops being a second transcript renderer.
  The picture-in-picture keeps the Swift `CaptionPainter` (it must make bitmaps).

## Rules
1. **Home = the page of what is playing or was last open.** Video picture on top when the item is video. Then one column in time order:
   transcript lines (lit as they play; the translation under the current line per "Follow in") with your typed lines, ink and voice notes between them at their moments.
2. **Typing at any point writes a note line anchored to that moment** (FEAT-23 moment link `[mm:ss](recense://<key>?t=<s>)`).
3. **The note file holds only your words, ink and moment links** (FEAT-23 rule 4): the transcript is never copied in. A corrected transcript re-weaves everywhere.
4. **Top of Home: Open to-dos**, then the page. A to-do is a Markdown `- [ ]` line in any note or Draftpad page, typed or spoken (`shared/voiceappend.swift`).
   The note file stays the source of truth; calendar sync is FEAT-27 and is derived from it.
5. **The sound bar stays** (`MiniPlayer`, `Views/Root.swift:56-62`). Tapping it opens the same woven page full screen in transcript-follow mode with "Follow the Playhead".
   The follow behaviour moves from Swift into the editor.
6. **Library** gets shows, episodes, Recently Played, Up Next and the places (`EntryList`, `Rail`, unchanged).
   The Now Playing sheet is removed: `model.play()` opens Home instead of setting `nowPlayingOpen` (`ShowsModel.swift:59,161,166`; `Views/Root.swift:26`). `SkinTests` that assert the sheet change with it.
7. **One WKWebView, held at the root:** Home, Draftpad and every note swap documents in it (FEAT-23 rule 3).
8. **Picture in Picture keeps working:** `CaptionLayer` (hosted by `mobile/HostApp/iOS/ListeningCard.swift:28` and `Listen.swift:1423`) moves into the sound bar, so leaving the app from Home still floats.
9. **Every action has a visible control** (law: no gesture alone): Note, Open to-dos, Follow the Playhead, the pill and the scrubber are on the page; gestures only speed them up.
10. **Reduce Motion:** the weave never animates a reflow; lines swap in place. **Easy on the eyes:** one narrow column, large type, no more than one lit line plus its translation moving at a time.

## Assumptions and risks
- **assumed** 60 Hz lighting in a WKWebView is smooth on an iPhone 12 Pro Max. The Mac already hosts `prosody.js` in one. Proven by the FEAT-20 light-error recorder (the device check).
- **assumed** one WKWebView can swap documents without a visible reload flash. P3's device check proves it.
- Risk: the weave is the one renderer, so a bug in `weave.js` shows on every device at once. The P1 tests and the debug channel guard it.
