A native macOS utility that acts as a persistent, gesture-summoned extension of memory: a minimal floating Markdown workspace that can surface over any window, capture thought through voice or typing, and return to the background without interrupting flow. It is local-first, designed around low-friction interaction, and built around one portable Markdown source of truth that can sync with Obsidian. The project explores how voice, gestures, contextual information, and AI can become a quiet layer between human intent and the computer.
