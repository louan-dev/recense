# Sill — Claude Project Knowledge

These files are intended to be uploaded to the **Knowledge** section of the Claude Project for Sill.

## Recommended upload set

Upload all files in this folder. Claude can then retrieve the relevant document instead of carrying the entire product brief in Project Instructions.

### File roles

- `00_NORTH_STAR.md` — enduring product purpose and conceptual direction
- `01_CURRENT_STATE.md` — what is currently true/implemented or known
- `02_ARCHITECTURE.md` — system and data architecture
- `03_DESIGN_PHILOSOPHY.md` — interaction and visual principles
- `04_IDEAS.md` — preserved future and exploratory concepts
- `05_PROPRIETARY_DIRECTIONS.md` — potentially differentiating/unpublished directions
- `06_DECISIONS.md` — choices already made
- `07_INTEGRATIONS.md` — external/system integrations and boundaries
- `08_DEVICE_MATRIX.md` — hardware, platform, and testing constraints
- `09_CHANGELOG.md` — evolution of the project knowledge set

## Important rule

These documents are not all requirements.

In particular, `04_IDEAS.md` contains possibilities that should remain exploratory unless a decision explicitly promotes them.

The Project Instructions should remain the behavioral constitution for Claude; these files are the durable product memory.
