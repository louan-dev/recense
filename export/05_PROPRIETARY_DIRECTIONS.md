# Recense — Proprietary / Differentiating Directions

This document identifies ideas that may be strategically differentiated or potentially unpublished. It is not a legal opinion about novelty or patentability.

## Intent Ledger

A central conceptual differentiator is the idea of one continuous page serving simultaneously as:

- memory
- command surface
- action history
- contextual scratchpad
- durable audit trail

The page is not merely a note. It can become the durable record of what the user thought, asked, drafted, and authorized.

## Temporal Relationship Between Media and Thought

A potentially differentiated direction is preserving time-indexed relationships between:

- audio spans
- transcript ranges
- Markdown positions
- later summaries or transformations

The important property is lineage: a future user or agent can move backward from a conclusion to the underlying thought or recording.

## Interleaved Voice + Text

Another potentially differentiated idea is allowing voice and text to coexist on the same continuous page in whatever order is natural, rather than maintaining separate voice-note and text-note products.

Potential model:

```text
typed thought
voice thought
AI response
another typed thought
voice recording
summary
```

All belong to one evolving conceptual stream while underlying media remains independently stored as needed.

## Summon / Dismiss State Continuity

The interaction model itself may be differentiated by treating summon/dismiss as a continuity operation rather than opening and closing a conventional app window.

The user should be able to leave the surface and return without having to rebuild the cognitive context.

## Open File Convention

The use of a normal Markdown file as the durable source of truth may support an ecosystem strategy:

- data remains portable
- Obsidian can continue to access it
- other tools can read it
- Recense does not need to become the exclusive data owner

The ecosystem value comes from an open persistence convention rather than a proprietary database.

## Combination vs. Individual Features

Prior art exists for floating notes, dictation, transcription, AI assistants, command palettes, and contextual system utilities.

The potentially interesting differentiation is the combination and interaction grammar rather than claiming that any individual capability is novel.

Do not disclose potentially unpublished implementation mechanisms publicly without deliberate review.

## Confidentiality Boundary

Until publication decisions are made, treat specific architecture, interaction mechanisms, implementation tricks, and differentiation hypotheses as potentially unpublished.

Do not make public novelty or patentability claims without qualified legal analysis.
